# 🎲 Randomicon

Uma página _web_ completamente _offline_ para testar e usar de funcionalidades envolvendo geração de números pseudo-aleatórios.

Um projeto simples, mas que estava querendo fazer há um bom tempo. Está sendo útil tanto para exercitar habilidades de desenvolvimento _web_ como para uso pessoal - não foi só uma vez que precisei fazer um sorteio de valores ou nomes em lugares com Internet instável e/ou de uma forma mais prática.
> Nota: a aplicação utiliza `crypto.getRandomValues()` no lugar de `Math.random()` para aquisição de valores mais imprevísiveis.

Trabalho em progresso - WIP.

## Como usar?
Basta descompactar o projeto em uma pasta e abrir o arquivo `index.html` através do navegador _web_ do seu computador. Alterne as funcionalidades disponíveis através dos botões no topo da página.

## Funcionalidades
- Sorteador de números
- Embaralhador de listas
- Sorteador de nome da sorte (fruta/vegetal + adjetivo)
    - Inspirado no mecanismo de nomeação do [LocalSend](https://github.com/localsend/localsend)
